# 活动签到：失败矩阵

| 条件 | 旧流程表现 | 修正后表现 |
| --- | --- | --- |
| 发送 `21003` 后没有回包 | 等待“活动签到状态”至超时，后续任务受阻 | 不发送 `21003`，直接使用登录快照。 |
| 登录快照没有 `Game_data` | 不能正确识别原因 | 跳过并显示“登录快照未包含活动签到状态”。 |
| 登录快照不含签到活动 | 空同步结果 | 跳过并显示“登录快照没有活动签到数据”。 |
| `ticket.status != 1` | 旧流程会对所有活动盲发领取 | 不发领取请求。 |
| `todaySigned = true` | 旧流程会对所有活动盲发领取 | 不发领取请求。 |
| `21000.ret != 0` | 计为普通跳过但没有资格上下文 | 记录活动 ID 与 `ret`，继续处理其他候选。 |
| 任务被停止 | 未显式标注中断 | 停止后保留已完成结果并标记 `stopped`。 |
