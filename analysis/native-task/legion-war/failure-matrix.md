# 失败与等待矩阵

| 现象 | 已证实原因 | 未证实项 | 应等待/应发送 | 下一步证据 |
| --- | --- | --- | --- | --- |
| 围攻列表为空 | 当前没有满足 `progress > 100 && trapped_left_seconds == 0` 的城堡。 | 其他城堡字段是否影响资格。 | 不发 `20075`，进入税收门。 | `20074` 原始帧。 |
| 收税提示“有城堡正在遭受围攻” | 本地化 `collectTax.ret5` 和页面提示都要求先突围。 | 服务器是否将 `trapped_legion_battle` 也作为硬门槛。 | 回到 `20074`，处理待突围城堡；不得盲目重发 `20080`。 | 围攻状态和 `20080 ret5` 帧。 |
| `20075` 返回 `ret=5` | 服务端返回已有军团战；旧战斗状态可能先于响应到达，也可能只留在延迟队列。 | 服务端清理响应的详细 message。 | 先消费 `20055/20061` 恢复；无状态时发送空 `20062`，最多重试一次 `20075`。其他 ret 立即停止并保留 message。 | `20075`、`20062` 成对帧及延迟队列。 |
| `20075` 返回其他失败 | 结果字段 `10 != 0`；本地化已定义无效城堡、未占领、未围困、发起军团战失败等语义。 | 具体 ret 到文案的版本映射。 | 停止当前日常并保留 ret、message 与城堡 ID。 | 同一版本的 `20075` S->C 帧。 |
| 军团战无法开始 | `20054.ret != 0`；当前运行时 `ret=20` 搭配 message `officer num exceed`，根因是发送军官数超过原生槽位宏 `ma_legion_officer_slot_num=5`。 | 服务器是否还要求未公开字段。 | 按宏限制截断到 5 名军官；仍失败则不重发，记录 `ret/message`。 | `20054` + 前导 `20055/20050` 帧；`macros.json`。 |
| 未下发战术候选 | `turn > 0` 时候选为空，可能是战斗结算过渡态。 | 是否存在额外候选来源。 | 不发 `20057`；等待下一条 `20055` 或 `20061`。 | `20055` 原始帧与当前版本战术表。 |
| 战术被拒绝 | `20057` 响应字段 `2 != 0`；页面列出不在决策期、不在选项、无效策略、材料不足。 | 各错误码的完整时序。 | 停止并记录当前战术候选；不选择未下发策略。 | `20055 -> 20057` 成对帧。 |
| 战斗结算失败 | `20061.field1 != 1`。 | 失败的详细原因与是否可立即重试。 | 终止税收、招募和募兵升级。 | `20061` 及后续围攻同步帧。 |
| 税收已领取 | `20074.today_tax_collected=true` 或 `20080.ret != 0`。 | 每座城堡税收与顶层日标志的精确关系。 | 前者直接跳过；后者报错，不盲目重试。 | 当日多城堡收税帧。 |
| 招募失败 | `19532.field20 != 0`；页面列出无效奖池、次数/方式/道具 ID 错误、日限、余额不足。 | 服务端每日上限的实际计数规则。 | 记录请求字段和 ret；不改写横幅/类别/消耗。 | `19532` 成对帧。 |
| 募兵已满或材料不足 | 本地化 `upTroopsLv.ret1/ret2`；或本地当前等级缺失成本/道具不足。 | 服务器是否有额外等级门槛。 | 本地条件不足时跳过，不发送；已发送且失败时停止该步。 | `20064` 响应和 `20050/12602` 帧。 |
| 军官等级升级失败 | 页面有无效 ID、未解锁、等级上限、费用不足。 | 消息 ID、字段、实际成本和同步。 | 目前不得发送任何推测包。 | 仅操作该按钮的完整只读帧。 |
| 军官升阶失败 | 页面有无效 ID、未解锁、稀有度上限、费用不足。 | 消息 ID、字段、实际材料扣除和同步。 | 目前不得发送任何推测包。 | 仅操作该按钮的完整只读帧。 |
| 请求后流程停住 | 可能在等待 `20055`、`20061`、背包变更或军团同步。 | 客户端页面动画回调是否参与后续发送。 | 先等待原始状态/推送，不重发入口。 | 带时间戳的完整采集窗口。 |
